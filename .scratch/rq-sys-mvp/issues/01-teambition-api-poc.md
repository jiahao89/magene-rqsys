# [done: 2026-10-08] 01 — 验证 Teambition API 与字段映射

## 目标
在指定产品组项目中验证初始全量同步和后续增量/重复同步所需的真实 API 契约。

## 范围
- 验证应用授权、项目查询、需求列表/详情、稳定需求 ID、分页、排序和更新时间筛选。
- 逐字段记录 PRD 范围内的来源：标题、描述、范围、验收标准、提出人、执行人/负责人 ID 与姓名、状态、时间、链接、附件引用及获批自定义字段。
- 验证负责人缺失、字段为空、权限不足、限流和单条失败的返回行为。
- 确认项目 ID + 需求 ID 可作为幂等键；不稳定时停止进入业务同步实现并提交决策。

## 验收标准
- 形成字段映射表：API 字段/类型/空值/是否可读/样例及未覆盖原因。
- 形成分页与增量拉取的实际请求和响应证据，遮蔽 token/个人敏感信息。
- 明确全量导入范围及重复同步判断方式。
- 硬编码默认 API key fallback 只留在服务端 helper，未写入浏览器包、配置回显或日志。

## 不在范围
写入 Teambition、标题推断 ID、或引入 PRD 外字段。
