# PR-08 角色与权限最小集

> 批次：2026-11-06 生产就绪（PR）
> **Status**：`cancelled`（2026-11-09 用户决定现在不需要角色/权限）
> **优先级**：P1
> **创建**：2026-11-06；基线：root `5490d75`

## 背景 / 目标

当前仅要求飞书登录，没有 RQ-Sys 角色：任何登录租户用户都可改数据源/周计划、增删人员、改模块词典、发布优先级规则、做重复判定、设人工优先级、分配负责人；没有只读角色；危险操作只有前端确认，没有服务端权限收口。目标：收敛最小角色矩阵并在服务端强制。

## 范围

- 角色矩阵（最小集）：管理员（数据源/规则/人员/模块/密钥相关配置）、PM（需求/评分/判定/负责人/重跑）、只读（查看+导出）；明确每个端点/操作的角色要求。
- 服务端强制：`apps/api/src/http/app.ts` 及用例层权限检查；前端按角色隐藏入口（隐藏不作为安全边界）。
- 高风险操作（发布规则、改数据源、删人员、删除/清空负责人等）审计 + 二次确认。
- 修订 `OPEN-DECISIONS.md` D-04（当前决策是「所有登录租户用户可用、不加角色矩阵」），记录变更理由。
- 至少两个账号做权限回归（管理员 vs 只读）。

## 验收标准（未取得目标环境证据前不得宣称完成）

- [ ] 角色矩阵文档落库（角色、可访问端点、前端入口、审计要求）。
- [ ] 服务端强制实现：只读账号对写端点返回 403；PM 无法改全局配置；管理员可管理配置。
- [ ] 前端按角色隐藏/禁用入口，且与后端一致。
- [ ] 高风险操作审计记录 actor/操作/前后值/时间；二次确认可用。
- [ ] 至少 2 个账号在目标环境完成权限回归（有记录）。
- [ ] D-04 决策修订记录（若用户确认改变访问模型）。
