## Acceptance criteria

- [ ] V02-T21-AC01：详情展示当前综合分、P0–P3、评分置信度、版本/时间、AI/人工/已采用AI标签；无评分显示“待评分/可手动填写”，失败显示重试。
- [ ] V02-T21-AC02：九项表格同时显示AI建议、当前值、依据/假设、是否假设；α单独展示默认依据和当前值；公式与阈值只读展示。
- [ ] V02-T21-AC03：编辑态支持修改任一输入项和α；范围/步长校验；修改理由必填；实时预览综合分/P；保存调用T20 API，取消恢复当前值。
- [ ] V02-T21-AC04：AI建议与当前值不同时显示差异；支持“采用AI建议”（需确认）；保存/采用后刷新当前值并显示新版本。
- [ ] V02-T21-AC05：版本历史显示版本、来源、操作者、时间、分数/P、修改项、理由；只读；旧版本可查看。
- [ ] V02-T21-AC06：加载/空/失败/409冲突/规则未发布状态均有明确文案和下一步；冲突保留用户输入并可刷新重试。
- [ ] V02-T21-AC07：不提供编辑公式、阈值或最终P；不把评分编辑绑到Base推送/通知；窄屏/键盘可操作；无PII泄漏。
- [ ] V02-T21-AC08：组件测试覆盖展示/编辑/校验/保存/采用AI/冲突/历史/空失败；两仓UI行为对齐；typecheck/build通过。
