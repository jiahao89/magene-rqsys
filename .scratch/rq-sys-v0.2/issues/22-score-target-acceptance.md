# 22: 评分v2目标环境验收

**What to build:** 在目标环境用受控合成需求验证评分v2：AI九项评分/依据/假设、服务端公式与P、PM改单项和α、版本/审计、AI重跑不覆盖、安全复核提示、失败隔离、Base当前P投影及清理。

**Blocked by:** 19、20、21、G-DEPLOY

**Status:** ready-for-agent（2026-10-27：随评分v2拆分；目标写入须另行授权执行）

**Approval:** 用户于2026-10-27确认评分v2需求；目标合成需求写入与清理须按项目目标授权门禁执行。

**Spec:** [V02-S06](../../../specs/rq-sys-v0.2/06-ai-scoring-and-priority.md)

**Execution gate:** 目标数据库迁移、发布、合成需求/Base写入和清理须获目标环境授权；不得用真实需求做验收。

## Acceptance criteria

- [ ] V02-T22-AC01：目标release和迁移/规则v2已部署；仅创建明确标记的合成需求；记录批次/作业/清理方案，不向干系人发消息。
- [ ] V02-T22-AC02：真实模型对合成需求输出九项分数+α、逐项依据/假设、总体说明和置信度；证据可在原文核对；AI不得自报最终P。
- [ ] V02-T22-AC03：服务端综合分/P与公式一致；6条校准样例（6.40/8.53/16.00/15.20/12.16/3.20）在规则/测试中可复算；边界45/25/10正确。
- [ ] V02-T22-AC04：目标UI可编辑单项和α并保存；重算/版本/审计正确；409冲突可恢复；AI建议与当前值分离。
- [ ] V02-T22-AC05：AI重跑生成新建议但不覆盖人工确认值；显式采用AI后当前值切换；旧版本只读。
- [ ] V02-T22-AC06：安全标记只显示复核提示，不自动改P；评分失败/缺失/规则未发布不阻断需求详情/主流程。
- [ ] V02-T22-AC07：当前P按既有Base推送投影，同一需求不重复行；人工改分不自动推送/通知；活动作业归零。
- [ ] V02-T22-AC08：清理合成需求/评分版本/审计/Base行；回读需求/手工/Base/活动作业基线；记录截图/API/DB/审计证据，更新T22与报告。
- [ ] V02-T22-AC09：目标证据只记录在本票；不以本地测试或未授权目标写入代替；失败/回滚步骤明确。

目标：受控合成需求 + 真实模型 + 目标API/DB只读回读 + UI截图；本地：公式/契约/版本/UI测试全绿；两仓对齐。通过后本票标记`target-verified`，否则保留`ready-for-agent`并记录阻塞。
