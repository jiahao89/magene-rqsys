# 02: 扩展统一来源身份并读回现有TB记录

**What to build:** 现有需求可看到来源类型和稳定平台编号，数据结构允许手工来源；所有既有TB记录、版本和关联完整保留。

**Blocked by:** 01 收敛共同工作流入口并保持TB行为

**Status:** draft — 待测试接缝/任务拆分确认，尚未发布为 ready-for-agent。

**Spec:** V02-S00

## Acceptance criteria

- [ ] V02-T02-AC01：新增迁移扩展来源类型、手工可空TB字段、业务渠道/最小上下文字段及来源分支约束；来源配置仍只管理TB项目。
- [ ] V02-T02-AC02：TB来源仍按原项目内TB ID唯一；手工来源不需要来源配置、不使用假TB ID或fake sync batch。

- [ ] V02-T02-AC07：先扩展和验证约束，后续切片再开启手工写入；根SQL迁移和妙搭schema契约对应，不改已应用迁移。
