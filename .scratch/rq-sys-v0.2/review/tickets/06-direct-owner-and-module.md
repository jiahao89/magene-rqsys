# 06: 需求级选择模块与负责人并通知分配人

**What to build:** 录入人选择模块及需求负责人，人工分配首推和后续改派通知正确的人，其他需求不受影响。

**Blocked by:** 04 最小新建需求贯通AI与Base

**Status:** draft — 待测试接缝/任务拆分确认，尚未发布为 ready-for-agent。

**Spec:** V02-S00、V02-S01、V02-S03

**Execution gate:** 无额外产品门槛；目标环境写入仍遵守项目授权门禁。

## Acceptance criteria

- [ ] V02-T06-AC01：按需求保存飞书ID、ID类型、分配来源、分配版本和历史；手工需求不创建TB人员映射。
- [ ] V02-T06-AC02：同一飞书负责人可分配多条需求；改派单条不批量改动其他条。
- [ ] V02-T06-AC03：模块关联人只提示候选，点击确认才分配；无绑定、绑定歧义或未解析时可留空。
- [ ] V02-T06-AC04：Web录入模块、AI建议与Base PM确认模块分开；人工模块不会被AI或字典更新静默覆盖。
- [ ] V02-T06-AC05：首推人工分配通知该负责人；自动匹配批量首推静默，重复操作不重复通知。
- [ ] V02-T06-AC06：改派事件按分配版本和身份去重，包含A→B→A；显式新分配写Base，不由旧本地分配反复覆盖Base人工改派。
- [ ] V02-T06-AC07：内容变更/AI重试成功从本次有效分配或Base当前负责人选人，无负责人时回落王赵云；读取失败不当作无负责人。
- [ ] V02-T06-AC08：负责人事件与原Base负责人变化自动化共同验证只发一次；正确处理不同ID类型分段写入及失败重试。
- [ ] V02-T06-AC09：无负责人允许推送；显式清空已有Base人工负责人不在本期。
