## 发现的问题

### P1 视觉：暗色模式只切了一半（全局）

- 现象：切到暗色后，表格、侧边栏项、按钮都是暗色，但**页面画布仍是白色**，形成白底 + 黑表格的混合态。
- 证据：`ui-18-dark.png`、`ui-20-dark-overview.png`；`document.body/html` computed background 为 `rgba(0,0,0,0)`。
- 根因：`styles.css` 里 `html, body { background: var(--rq-canvas) }`，而 `--rq-canvas: var(--color-fill-2)` 声明在 `:root`；Arco 的 `--color-fill-2` 只在 `body[arco-theme]` 上有值，所以在 `:root` 解析为空，画布透明 → 浏览器默认白底。亮色下白底恰好看不出来，暗色下暴露。
- 影响：暗色模式不可用（不是白屏，但明显视觉缺陷）。旧版暗色截图正常，属本次重写的回归。

### P1 布局：1000 宽下需求池表格右侧列不可达

- 现象：视口 1000 时，`.table-scroll.req-list-scroll` 自身宽 **1170**、起点 x=256（右边界 1426），页面 `scrollWidth=985`（不出现横向滚动）→ 「更新时间」「操作」列被裁掉且无法滚动查看。
- 证据：`ui-16-narrow-1000.png`、`ui-16b-narrow-1000.png`；表格内 操作列表头 x=1306、宽 120，远超视口。
- 根因方向：表格容器没有被约束到内容区宽度（flex/grid 子项缺 `min-width: 0` 或容器用了内容宽度），外层又把横向溢出裁掉。
- 1440 下正常（1170+256 < 1440）。
