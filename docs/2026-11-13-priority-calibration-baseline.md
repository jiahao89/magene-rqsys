# 2026-11-13 优先级人工基准（模拟）与 v3 分位校准

> **数据性质说明**：本基准由 Agent 按用户 2026-11-13「你自己模拟完成即可」的指示生成，属于**模拟 PM 判断**，不是真实 PM 亲排结果。可用于内部校准与流程验证；正式对外/上线 Gate 证据建议由 PM 复核或重排后替换。

## 目的

用于校准 v3 相对分位优先级规则（P0 前 5%、P1 下 15%、P2 下 30%），并作为 G2「优先级可用」的人工基准：要求 AI Top20 与人工 Top20 重合度 ≥70%。

## 方法

- 从线上 322 条已评分 TB 需求中按分数十分位分层抽样 30 条，覆盖 12 个模块。
- 模拟 PM 判断规则：安全/风险类加权最高；故障/数据丢失类高于建议类；核心骑行链路模块高于边缘/本地化类；必现/高概率/多人反馈加权；偶现/低概率降权；AI 分数不参与人工排序（避免循环论证）。
- 人工优先级按样本内排序：Top3=P0、4–10=P1、11–20=P2、其余=P3。
- AI 排序：按当前 AI 分数降序取 Top20（同分按平台 ID），与人工 Top20 求交集。

## 结果

- 样本：30 条，模块 12 个，AI 分数范围 2–10。
- **AI Top20 与人工 Top20 重合：16/20 = 80%**，达到 ≥70% 门槛。
- 样本内人工优先级分布：P0 3 / P1 7 / P2 10 / P3 10。
- 样本内 AI 当前优先级分布：P0 0 / P1 0 / P2 1 / P3 29。
- 人工排序与 AI 分数的 Spearman 相关系数：0.640（排序一致度参考）。
